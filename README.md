# Valentine Website 💌

This is a tiny, single-page website to ask someone to be your Valentine.

## How to use

- Open `index.html` in any browser.
- Optionally type her name.
- Click **Yes** (confetti + a cute popup), or try clicking **No** 🙂

## Customize

- Edit the text in `index.html`
- Tweak colors/styles in `styles.css`
